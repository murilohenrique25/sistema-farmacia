# sistema-farmacia

Sistema de gestão de entregas de farmácia, composto por API Java, painel Angular, aplicativo Flutter e página de rastreamento.

## Tecnologias

- TypeScript
- Python
- Java
- Maven
- Dart
- Flutter
- Spring Boot
- Angular
- Angular Material
- Bootstrap
- Leaflet
- GetX
- Dio
- PostgreSQL
- MySQL
- WebSocket
- HTML
- CSS

- [control-api](control-api/README.md)
- [control-delivery](control-delivery/README.md)
- [entregaja_delivery](entregaja_delivery/README.md)
- [rastrear](rastrear/README.md)


## Publicação no GitHub

Este repositório reúne o código-fonte e a documentação do projeto. Dependências instaladas, builds, backups, bancos locais e chaves privadas não acompanham a publicação. As configurações sensíveis identificadas foram substituídas por marcadores ou referências a variáveis de ambiente; configure seus próprios valores antes de executar os componentes.
